# Лабораторная работа № 3. Кейс 3 — acc-5

## Условия

| Параметр | Значение |
|---|---:|
| Аккаунт | acc-5 |
| Частота поступления | 2 заявки/с |
| Число заявок | 500 |
| Срок обработки каждой заявки | 60 с |
| Требуемая успешность | выше 97% каждую минуту |
| Требуемое отношение дохода к расходам | не менее 93/7 = 13,2857 |
| Наблюдаемость | собственная метрика и дашборд Grafana |

60 секунд — срок обработки одной заявки, а не длительность всего теста. Поступление 500 заявок занимает около 250 секунд; последний срок истекает примерно через 310 секунд после начала.

Параметры провайдера для `cas-m3404-01`: не более 5 параллельных запросов, не более 3 вызовов в секунду, среднее время обработки — 4,9 секунды, стоимость вызова — 30.

## Почему требования не выполняются

При среднем времени 4,9 секунды пять параллельных слотов обеспечивают около `5 / 4,9 = 1,02` завершения в секунду. Ограничение по частоте вызовов — 3 в секунду, поэтому узкое место — параллельные слоты. Входная нагрузка составляет 2 заявки в секунду, и очередь растёт.

Для успешности выше 97% нужно обработать не менее 486 из 500 заявок. При среднем времени 4,9 секунды для этого требуется около 2381 слот-секунды. За 310 секунд пять слотов могут дать не более 1550 слот-секунд. Это оценка по среднему времени, а не строгая граница для каждой случайной выборки.

Для устойчивой обработки нагрузки 2 заявки в секунду нужно не менее 10 параллельных слотов. Увеличение числа потоков приложения не меняет лимит аккаунта.


## Вывод

При текущих ограничениях acc-5 средняя пропускная способность ниже входной нагрузки. Резерв времени сокращает расходы на поздние вызовы, но не обеспечивает требуемую успешность.
